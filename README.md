# Drug Discovery Data Catalog

A reproducible scientific data engineering pipeline for integrating,
standardizing, validating, and cataloging compound-target bioactivity data
from public drug discovery sources.

## Planned Sources

- ChEMBL
- PubChem

## Core Goals

- ingest scientific data from heterogeneous sources
- preserve raw source data
- standardize compound and activity metadata
- store curated data in PostgreSQL
- track source metadata and end-to-end provenance
- detect duplicates and data quality issues
- support reproducible SQL-based data discovery
